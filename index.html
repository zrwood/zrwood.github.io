Current project

Robot Training Optimization

In progress · Fall 2026
Lab Computational & Physical Intelligence Lab, CMU Advisor Liwei Wang Tools Python, genetic algorithms, robot simulation on GPUs

Each robot is a lattice of cells joined by springs. Some springs are passive skeleton; others are muscles that expand and contract. A genetic algorithm proposes body designs, and every design is evaluated two ways. The first trains a controller for the body as it was proposed (ELDiR). The second, co-design, adjusts the body's materials while it learns the controller, then hands the changed body on to its offspring. Both versions compete for the same places in the next generation.

The simulation

Robots live in a 2D physics simulator written in Taichi. It runs on a GPU and is differentiable: it can report how the distance a robot travels would change if any part of the robot or its controller changed. A body is built from a grid of 60 triangular cells, and the edges of its cells are springs. Muscle springs lengthen and shorten on commands from a small neural network controller. A robot's score is how far its center moves during one simulated run.

Five terrains

Skeleton spring (passive) Muscle spring (actuated)

This is ongoing lab research, so the code is not public.
